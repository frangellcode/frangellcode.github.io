# frangellcode.github.io

The privacy policy and support pages of every Frangell Code app, served by
GitHub Pages at `https://frangellcode.github.io/<app>/`. The App Store listings
link to these addresses, so file names and folders must never change.

One folder per app:

| App | Folder | Pages |
|---|---|---|
| PolarGrid | `polargrid/` | `privacy.html`, `support.html` |
| PolarBoom | `polarboom/` | `privacy.html`, `support.html` |

Rules:

- Only legal and support pages here. Never an app build: the apps are App Store
  only, and a web build here would give them away for free.
- The app repos are private; this is the only public repo, and the only source
  of these pages. Edit them here.
- A new app: add its folder, a line in the table above and one in `index.html`.

`polargrid/sw.js` and `polarboom/sw.js` retire the old installed web versions of
PolarGrid and PolarBoom; keep them.
